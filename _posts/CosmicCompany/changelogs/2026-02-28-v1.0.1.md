# Lethal Company Revitalized v1.0.1

## Additions
- More cosmetics and suits!
- Mimic Monster
- Men Stalker Monster
- Better HUD


## Removals
- Removed Rats mod.
- Removed "The Thing" - due to log spamming when unable to find a suitable spawning location.


## Tweaks

### Lethal Interns
- You can now spectate purchased Interns when dead.
- Interns are now viewable on the Ship's monitor.
- Internship Program on the terminal renamed to "COSMIC INTERNS".
- Interns now take the suit appearence of the Player they're assigned to.
- Interns can now grab dead bodies, the Baby Maneater, Shopping Carts and Wheelbarrows.

### Masked
- Masked players now appear alive on the Ship's monitor.
- Masked entities take the appearance of the Player.
- Masked entities show Player's name tag.
- Masked entities no longer spin on the Ship's monitor.
- Masked entities no longer wear masks.

### Ship
- Reworked Ship monitors.
- Weather multipliers are now displayed on the Ship terminal.
- Slower terminal scrolling for better accuracy

### Store
- Late Game Upgrades now uses a seperate currency for puchasing upgrades.


### Players
- Players can now sprint up ladders by using some extra stamina.
- Scanning is now more accurate.
- When a Player rolls an emergancy dice, it now shows what was rolled in the chat.

### Environment
- Reworked all weather multipliers and chances.

### UI
- New messages when loading a planet
- Updated loading screen



## Fixes
- Fixed the loading screen files being in the wrong place - resulting in the custom image not loading.
- Fixed the terminal not allowing moons to be viewed.
- Cleaned up a lot of log spam.
- Performance improvements (including faster loading times, less stuttering during planet gameplay).
- Removed LethalLevelLoaderUpdates dependancy string (depreciated).
